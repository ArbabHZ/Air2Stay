Using Air2Stay responsibly

Local demonstration guidance · 1 November 2026. These are application instructions, not an official DCT, Oracle or employer policy. Add the organisation's approved policies before workplace deployment.

A practical walkthrough

  1. Choose a departure country and month. For a country without flight history, choose + New route, select a country and confirm it.
  2. Set the weekly flights and check the flight and hotel assumptions. A comparison country is only a starting point.
  3. Read Focus for the estimated change. Open Details for the calculation and source limits.
  4. Use Compare to test flight options, months and lower assumptions. Guest nights do not equal hotel rooms.
  5. Open Actions. Review priority checks, record an owner and a due date, add evidence, and save a version before making a decision.
  6. Draft an airline inquiry, hotel-capacity request or team summary. Review it, then copy or download it. Air2Stay does not send messages or receive replies.

Where records live

Proposal versions, comments, discussions, actions, evidence and decisions are stored in this browser on this computer. They are not synchronised to teammates. Clearing browser storage can remove them. Export a local record if it needs to be kept. If storage is unavailable or full, a warning explains that records are only available for the current session.

Follow-up dates are checked when the app is opened or used; there are no background email reminders. Use a real organisation-approved task and communication system for operational work.

Feedback and usage counts

Helpful ratings and problem reports are kept locally for this demo; they are not sent to a support team. Usage counting is off by default. If enabled in Guide me, it counts named feature and guide events locally. It does not record question text, search text or personal identifiers. You can turn counting off and clear the counts.

Before acting on a result

  • Ask the airline about the schedule, aircraft seats, expected bookings, occupancy and onward journeys.
  • Ask tourism and hotel teams about likely hotel use, stay length, available rooms and guests per room.
  • Use Red/Amber/Green as check status only. Green does not mean the route is profitable, accurate or approved.
  • Keep assumptions separate from measured facts. The aggregate accuracy test does not establish new-route accuracy.
  • Follow the competition's and your organisation's rules when sharing supplied records or exports.
